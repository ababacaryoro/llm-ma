# Corpus « orion »

Note de cadrage fictive d'un projet d'assistant interne dans une entreprise imaginaire. Noms, chiffres et dates sont inventés : le modèle ne peut pas les connaître.

Corpus de secours du TP « rappels LLM », si le corpus réel par défaut devient connu des modèles. Bascule : `RAG_CORPUS=orion` dans `.env`, ou `CORPUS = "orion"` en tête du notebook.
